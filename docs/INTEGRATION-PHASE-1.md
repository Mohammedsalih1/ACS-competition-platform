## 2. أعمال الدمج (7 سبتمبر)

### أ. دمج واجهة المصادقة (Awab)
- تاريخ Git غير مرتبط بـ `main` → تم نقل الملفات يدويًا بدلًا من دمج مباشر.
- استبدال `AuthContext.jsx` المؤقت بالتنفيذ الحقيقي.
- إصلاح خطأ: `AuthProvider` كان خارج `BrowserRouter`.
- ربط المسارات: `/login`, `/dashboard`, `/forbidden`, `/judge/*`.
- توحيد إصدار Tailwind على v4 وحل تعارض `package.json`.
- اكتشاف وإصلاح خطأ سابق: استيراد Tailwind كان معطّلاً بالكامل في `index.css`.

### ب. دمج نظام رفع الملفات (Zuhair)
- نفس مشكلة تاريخ Git غير المرتبط → نقل يدوي إلى `backend/src/`.
- **إعادة تصميم النموذج:** فصل البيانات إلى نموذجين بدلًا من واحد:
  - `Submission` — دورة حياة التحكيم (مسودة → مُرسل → قيد المراجعة → تم التقييم).
  - `File` — بيانات عملية الرفع (اسم الملف، الحجم، المسار، الحالة).
- توحيد أسماء الحقول (`contestant` بدلًا من `userId`) لتتوافق مع ما تعتمد عليه لوحة المحكّمين.
- إضافة مسار جديد: `POST /submissions` لإنشاء مشاركة (لم يكن موجودًا).
- إضافة طبقة تحقق `submission.validation.js` باستخدام Zod.
